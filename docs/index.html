Audit, security-scan & auto-update all your AI agent skills.

Skill Sync (skill-sync) keeps every installed SKILL.md repository and skills.sh package up to date across Antigravity, Claude Code, OpenAI Codex, Cursor, and Gemini CLI—with a pre-pull diff security gate, dirty-tree protection, and symlink deduplication. 

npx skills add jaxels1/skill-sync

Commands

/updates list

Dry-run scan listing every outdated git or skills.sh skill and asking what to update.

/update all

Security-gated fast-forward update for all clean repos and npx skills installs.

/updates diff <name>

Inspect upstream commits, security flags, and full diffs before pulling.

/updates status

Full symlink-deduplicated inventory audit across all agent directories.

Open-source on github.com/jaxels1/skill-sync.
